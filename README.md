# beforeSHOW

A movie platform backend built with Node.js, Express, and MongoDB.

beforeSHOW allows users to explore movies, rate and review them, while admins manage the movie catalog.

## Features

- User signup and login
- Password hashing with bcrypt
- JWT authentication
- User and Admin roles
- Admin-only movie management
- Movie listing and details
- Comments and ratings from 1–10
- Edit and delete own comments
- Average movie ratings
- "My Comments"
- MongoDB relationships using Mongoose `populate()`

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
